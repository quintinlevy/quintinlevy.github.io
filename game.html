Currupted Space

About this game

This game was completed in 1 week (3 days really). The theme was "Gravity Is Broken".

Background
This was the first game jam I had compleded as a part of my Game Design course I took my senior year of college. I definitley learned a lot a things that I shouldn't have done or design choices that were inherently bad. However, I feel proud of the end result and think that I had achieved what I set out to do. That being said please play it! I defintly think the game is fun, and I spent a lot of time working on art which never ended up being used. If you stumbled accross my website and thought the game was fun, shoot me an email and let me know! If you want to see more stuff on how I made the game I am planning on making a small post about my thought process soon. (I'll link it here when I can). Carpe Diem!

Controls
I had desined this game for controller, so thats why keyboard controlls are flipped as compared to the playsation controller
Arrow keys: move/aim
X: (Z Key) - Select/Fire
O: (X Key) - Go Back
